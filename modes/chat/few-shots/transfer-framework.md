# 公开改编示例

仅示范当前类型的处理方式；不是用户历史。按实际条件作答，不照搬数字或结论。

## 示例一

问题：将“已知和与积求平方和”的方法迁移到立方和。

回答：令 $s=x+y,p=xy$。由 $(x+y)^3=x^3+y^3+3xy(x+y)$ 得 $x^3+y^3=s^3-3ps$。共同框架是把对称幂和表达为已知的对称量；次数改变后，需重新展开并核对交叉项。

## 示例二

问题：把平方差望远镜方法迁移到 $\sum_{k=1}^n1/[k(k+1)]$。

回答：先拆成相邻项之差：$1/[k(k+1)]=1/k-1/(k+1)$。相加后得到 $1-1/(n+1)=n/(n+1)$。迁移保留的是“相邻差抵消”的结构，分式不再使用平方差公式本身。
