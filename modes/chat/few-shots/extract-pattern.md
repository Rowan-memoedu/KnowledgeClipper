# 公开改编示例

仅示范当前类型的处理方式；不是用户历史。按实际条件作答，不照搬数字或结论。

## 示例一

问题：从题目“$x+y=5,xy=4$，求 $x^2+y^2$”提取可复用方法。

回答：触发条件：给出两个数的和与积，目标是对称表达式。操作：展开和的幂，再利用积消去交叉项。本题用 $x^2+y^2=(x+y)^2-2xy=17$。边界：一般非对称目标（如单独的 $x-y$）还需要确定次序或符号。

## 示例二

问题：求 $1+3+5+\cdots+(2n-1)$ 有什么通用范式？

回答：识别相邻平方差：$2k-1=k^2-(k-1)^2$。求和后中间项抵消，得到 $n^2$。可迁移到“每一项是相邻量之差”的望远镜求和；不能仅凭数列递增就使用。
