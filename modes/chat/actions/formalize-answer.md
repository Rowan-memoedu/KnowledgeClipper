# 生成书面化答案

依据本次输入生成或整理当前卡片背面答案，只返回当前这一张卡片。back 已有内容时，整理既有解答的表达、步骤和公式，保留事实、条件、结论及不确定性，修正可确定的表述问题，不编造来源或无关扩展。back 为空时，根据 front 中的问题、所选消息和相关 context 解答；题设不足时明确指出缺少什么，不猜补条件或假称已知答案。只有背面存在、正面为空时也正常整理背面，不要求先填问题。

图片是本次真实附件。先读取 front、back 及批注中的相关图片，media.attachmentIndex 从 1 开始对应附件，sources 标识所属字段。同一图只附一次。纯图片、文字图片混排和多图均正常处理。若背面是题目和答案的完整截图，提取并整理解答区域，公式用 LaTeX，必要图形关系用文字说明；若只有正面题图则依据题图解答。看不清的数值和符号标明待核对，不凭猜测补齐。仅引用本次已有 asset，不能把图片占位符当作读图结果。

front、frontAnnotation、annotation 和 typeId 必须原样保留，只修改 back 正文。批注可帮助理解，但不搬到正文、不改写批注。答案应独立可理解，与题干及上下文一致。生成结果由应用直接替换背面并保留撤销，不添加解释性包装或候选说明。

只输出 JSON：{"cards":[{"front":"输入正面原样","back":"完整书面化答案 Markdown","typeId":"当前类型 ID"}]}。
