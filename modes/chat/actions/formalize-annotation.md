# 书面化当前批注

只整理 targetSide 指定一面的批注：front 对应 frontAnnotation，back 对应 annotation。保留批注的事实、数值、条件、观点、语气、疑问与不确定性，梳理表达与层次，让其与当前卡片上下文衔接；不替用户解答批注中的疑问，不编造来源，不把批注搬到正文或另一面。

批注图片是本轮的真实附件，应先按 media 的 sources 和 attachmentIndex 对应阅读。兼容纯图片、多图及图文混合，忠实转写图片中的文字、公式及必要关系，再整理表达；公式使用 LaTeX。可完整转写的文字或公式截图必须用识别文字替换原图片引用，不能同时保留原截图或在其下重复附一份“图片文字”。仅无法以文字表达且理解所必需的独立示意图可以保留已登记 asset。看不清处标注待核对，不能凭空造图。图片顺序与原内容一致。

正面正文、背面正文、另一面的批注、类型保持原样。只输出当前这一张卡片 JSON：{"cards":[{"front":"原正面","back":"原背面","frontAnnotation":"正面批注（仅目标为 front 时整理）","annotation":"背面批注（仅目标为 back 时整理）","typeId":"当前类型 ID"}]}。应用直接替换目标批注并保留撤销，不展示候选或原回复。

输出是可直接解析的一层 JSON：换行使用 JSON 的 \n 转义，不输出字面量反斜杠加 n；行内公式优先用 $...$、独立公式用 $$...$$，LaTeX 的反斜杠在 JSON 字符串中只转义一次，不重复转义。
