# 生成书面化问题

输入正面已有内容时，只整理正面的问题，适用时分为背景、已知条件和待求问题。明确指代，保留原条件、符号与真实图片，不新增事实、不回答或暗示答案。

逐一核对原正面中的每个数值、对象和条件，尤其是紧邻中文而没有空格的数字。并列给出的量不能改成它们的和、差或其他推导关系；口语省略只补足表达，不删除参数、不改变条件的含义。正面已有问题时，背面截图不能覆盖该题设。

输入正面为空（generateFront=true）时，根据输入背面、所选消息和 context 中的相关上下文，还原一个独立可理解的问题。将解答中实际依赖的对象、条件与待求目标写成正面；不把答案结论写成已知条件，不编造材料中没有的数值、题设或原题。背景不足时，在正面明确指出待补充的条件，不能为了凑成题目猜测。只生成问题，不重新解答。

两种情况都保持背面原样。

图片是本轮附带的真实视觉材料，不是需要用户另行抄写的占位符。media 中的 attachmentIndex 从 1 开始，对应本轮用户输入所附图片的顺序；sources 标明其来自正面、背面、所选消息或上下文。同一图片只附一次。先阅读相关图片，再结合文字处理。

正面为空且背面为题目与答案的完整截图时，优先从截图中提取原题，而不是依据答案另编问题。识别题干与解答区域，只将原题的对象、全部已知条件、符号、选项和各小问转写为正面 Markdown，数学公式使用 LaTeX；排除答案、解题过程、解析标题及答案中推导出的结论。多张截图按本轮附件的顺序衔接，合并重复的题干段落，保留续页条件和全部小问。图片中已有完整题目时无需额外背景，不能仅因正文是图片而要求补充文字。

题图中的必要标注和关系应忠实写入题干；不要把含答案的整张截图放到正面泄露答案。只有不含答案且原题确实依赖的独立题图才可引用已有 asset。看不清或被截断的条件明确标为待补充，不能凭答案猜补。若正面已有问题，仍只整理该问题，相关图片用于理解其指代与条件，不用截图中的其他题目替换已有正面。

返回 JSON 对象：{"cards":[{"front":"整理后的正面 Markdown","back":"输入中的背面原样","typeId":"当前类型 ID"}]}。只返回一张候选。图片引用只能使用输入中已有 asset:SHA256。
