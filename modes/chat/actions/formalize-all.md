# 全部书面化

这是对当前一张卡片的完整、原子化处理：同时整理 front（问题）、back（答案）、frontAnnotation（正面批注）、annotation（背面批注）。应用会一次替换四个字段并保留一次完整撤销，不生成额外卡片。

问题与答案的处理逻辑沿用前述“生成书面化问题”和“生成书面化答案”规则。它们的“不改另一面”分别约束各自子步骤，本动作最终应输出四个字段处理后的合并结果：
1. front 已有问题时保留题设，只整理表达；front 为空时，从 back、真实截图及相关上下文提取原问题，不把答案推导结论当作题设，也不另编题目。
2. back 已有答案时整理既有解答；back 为空时，依据正面问题及相关材料正常解答。只有问题或只有答案时都可完成。条件不足或图像不清时具体说明缺少什么，不猜补事实。
3. 两面批注分别整理表达与结构，保留全部观点、条件、数值、疑问和不确定性，与对应正文衔接但不搬移或合并到正文、另一面。某面的批注原来为空时保持为空，不自动增加学习建议或重复答案。

所有字段的图片均是本次真实附件，先按 media.sources 与 attachmentIndex 逐一读取，兼容纯图片、多图、图文混合。忠实提取题目、答案或批注所属内容，数学公式用 LaTeX；完整题解截图只把原题放正面、原答案放背面，不泄露答案到题设。必要独立图示可引用已有 asset，文字截图不能仅返回图片占位作为已整理结果。看不清的符号明确标注待核对。

可完整转写的文字与公式截图必须以识别文字替换原引用，不能保留原截图再重复附“图片文字”。仅无法用文字表达且理解所必需的独立示意图可以保留。输出为一层可解析 JSON，换行和 LaTeX 反斜杠只按 JSON 字符串转义一次，不输出二次转义的字面量换行或公式。

只返回一张卡片，typeId 原样保留，只输出 JSON：{"cards":[{"front":"完整书面化问题 Markdown","back":"完整书面化答案 Markdown","frontAnnotation":"完整正面批注 Markdown（原空则空）","annotation":"完整背面批注 Markdown（原空则空）","typeId":"当前类型 ID"}]}。
