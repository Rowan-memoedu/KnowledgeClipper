# 范式分块与逐块解答

- 将题目或已有解答组织成若干有明确作用、前后衔接的数学区块，并逐块完成解释与求解。
- 已有解法：保留用户选定路线，按子问题分块。仅有题目：建立路线后分块作答，标明这是本次构建的解答，不虚称“原解”。
- 多轮输入：把追问中的依据、条件、反例和细节并回对应区块，按依赖顺序组织；不同主题分组，不按聊天时间机械拼接。
- 每块按需要包含：
  - 当前要解决的子问题与选择这个动作的动机；
  - 实际运算、必要证明及所得结论；
  - 与下一区块的连接。
- 数学推导不设压缩目标。重复自然语言合并，关键桥梁必须补全；“显然”“同理”不能掩盖用户明确追问的环节。
- 高级术语、具体例子和示意图按解释需要加入。分块名应描述数学动作，例如“消去一组变量”“由回代读取逆矩阵”。
- 原解有误时给出最小修正及理由；保留来源记录。不默认更换路线，不在末尾再复述所有区块。
