# 独立剪藏插件的身份迁移

一次性迁移工具，不属于正常导入调用链。只扫描显式指定数据根下的 `language-drafts` 和 `excerpt-cards`，不会递归扫描其他目录，也不会修改草稿、设置或 Rem 内容。

```text
KnowledgeClipper.RemNoteMigration --prepare|--apply <旧 HTTP origin> <新 HTTP origin> <D盘证据目录> <数据根> [数据根...]
```

`--prepare` 从旧服务纯回读每个已写入／待核对的冻结计划，用生产 `RemNoteConnection.Validate` 验证内容、卡片、图片哈希和既有 ID，保存可审核的迁移输入。任何不一致单项失败并返回非零状态；不得通过修改草稿或原卡绕过。

`--apply` 重新完成上述核验，调用新插件的 `admin/adopt`，再从新服务纯回读并核对原 ID。插件只在真实 SDK 回读与身份、节点快照一致时保存自身导入记录；不会创建、移动或修改卡片。各草稿在前后进行文件哈希核对，检测并发改动。失败记录保留，重跑是同 ID 幂等操作。

迁移依赖旧服务仅用于此次取证。完成后，日常剪藏只使用独立服务的 43111/43112/43113，不需要旧服务或 MCP Bridge。旧记录证据不完整时保留待核对，不把新插件的空记录解释为未导入。

迁移证据可能包含原文和本机路径，必须保留在本机应用数据／产物目录，禁止提交到 Git。
